# /perseus:report

This command initiates the **Perseus Reporting** phase.

It invokes the `perseus:report` skill to:
1.  Synthesize findings from Scan and Audit phases.
2.  Prioritize verified risks.
3.  Generate a professional `SECURITY_REPORT.md`.

**Usage:**
Type `/report` when analysis is complete to generate the deliverables.
